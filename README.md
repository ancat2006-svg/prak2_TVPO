# Практическая работа №2 — Часть 1

Учебный модуль `MathModule` на Java для проведения модульного тестирования.

## Состав проекта
* `src/main/Main.java` — главная функция с примерами.
* `src/main/MathModule.java` — класс с 5 математическими методами.
* `src/test/MathModuleTest.java` — набор модульных тестов на JUnit 5.

## Результаты первичного запуска тестов
В результате запуска обнаружен 1 падение в методе `testCalculateTotalWithDelivery`:
* Ожидалось: `1800.0`
* Фактический результат: `1200.0`

## Окружение
* Java JDK 24
* JUnit 5
