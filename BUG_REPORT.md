# Отчёт об ошибке (Bug Report)

**Идентификатор:** BUG-01
**Краткое описание:** Неверный расчёт итоговой суммы заказа с доставкой.
**Статус:** Open
**Категория:** Major (серьёзная)
**Тестовый случай:** Проверка расчёта итоговой суммы с ненулевой стоимостью доставки.

## Описание ошибки
1. Запустить тесты командой `mvn test` или через IDE.
2. Выполняется тест `testCalculateTotalWithDeliveryWithFee`.
3. Входные данные: `orderAmount = 1500.0`, `deliveryFee = 300.0`.
4. Полученный результат: `1200.0`.
5. Ожидаемый результат: `1800.0`.

## Причина
В методе `calculateTotalWithDelivery` используется вычитание вместо сложения:
```java
return orderAmount - deliveryFee; // ОШИБКА: должно быть orderAmount + deliveryFee
